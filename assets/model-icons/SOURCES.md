# Model icon sources

The AGIBOT mark is cropped from the header logo published on the
[AGIBOT official website](https://www.agibot.com/public/static/index/en/images/logo2.png).

The VideoLLaMA2 mark is a resized copy of the
[official project logo](https://github.com/DAMO-NLP-SG/VideoLLaMA2/blob/e7bc34e0e9a96d77947a75b54399d9f96ccf209d/assets/logo.png)
at commit `e7bc34e0e9a96d77947a75b54399d9f96ccf209d`.

The Qwen, Google Gemini, NVIDIA, and ByteDance SVG marks are from
[Simple Icons 16.27.1](https://github.com/simple-icons/simple-icons), distributed
under the CC0-1.0 license. Other model families use local text badges.
